# Task Calendar

毎日のタスクを「日・週・月」の3つの視点で眺めながら、チェックボックスでこなしていく個人用タスクカレンダー。所要時間を設定したタスクはリング型カウントダウンタイマー（フォーカス画面）で集中して取り組める。完了の積み上げ（完了率・連続日数・週グラフ）を「振り返り」で見えるようにして、習慣づけを手伝う。

- 繰り返しタスク（毎日・毎週・毎月・毎年）と、タスクとは別の「予定」を追加できる
- 行を左へスワイプすると「編集／削除」
- 画面上部のEclipseトグルでライト／ダークを切り替えられ、設定画面ではOS追従やアクセントカラーも選べる
- デザインはオーナー作成のhandoff準拠（`specs/task-calendar-v2.md`・ADR参照）

## 使い方・起動方法

`index.html` をブラウザで開くだけ（ビルド不要・依存ゼロ・データはブラウザの `localStorage` に保存）。

GitHub Pages で公開している場合は **PWA** として使える：スマホでURLを開き「ホーム画面に追加」（iOS Safariは共有ボタン→ホーム画面に追加、Androidはメニュー→アプリをインストール）。以後はアプリのように起動でき、オフラインでも開ける。

1. **日**ビューでタスクを追加する（所要時間は任意。5/15/25/45/60分のプリセットあり）
2. 終わったらチェックボックスで完了。所要時間つきのタスクは「開始」でカウントダウンタイマーが起動する
3. **週**・**月**ビューで進み具合を振り返る（月ビューは完了がドットで積み上がって見える）

## テスト・動作確認の方法

v105: `node tests/v105.cjs` でタップによる6通知日の保存/解除/再読込、320/390/1440pxのデザインとヘッダー幅、OS明暗追従、アクアリウムタイマーの進捗/一時停止/完了記録を確認します。画像は `/tmp/taskare-v105`。iPhone実機の検証とは区別してください。

v104の追加機能: `node tests/v104.cjs`（下記と同じPlaywright環境）。通知日の保存・ノートのリンク安全性・語句抽出・3テーマのスマホ/PC明暗12画面を確認します。通知サーバーのテストは `reminder-worker/` 内で `npm ci` → `npm test`。

端末登録の失敗・解除・別端末の予定保護は `node --test tests/reminder-client.cjs`（外部通信なし）で確認できます。

PWA更新・31資材のキャッシュ・オフライン再起動は `node tests/offline.cjs`（Playwright環境）で確認できます。一時HTTPサーバーはテスト終了時に停止します。

**閉じたアプリへの通知は初期設定前には届きません。** [通知サーバーの設定手順](reminder-worker/README.md)を参照。アプリの公開だけでは配信は始まらず、専用サーバー・通知許可・実機受信の確認が必要です。

v102の回帰テストは `node tests/v102.cjs`（アプリディレクトリ内で実行）。PlaywrightとChromiumが必要。既存ブラウザを使う場合は `TASKARE_BROWSER` に実行ファイルのパスを指定する。外部通信を遮断した独立ブラウザと架空データで実行し、スクリーンショットは `/tmp/taskare-v102` に出力する。

原点ノートの回帰テスト: `node tests/origin.cjs`（同じPlaywright環境）。専用ページはメニューの「原点ノート」から開く。分類・理由・参考リンク・固定・削除取り消し・個人同期を確認し、画面を `/tmp/taskare-origin` に出力する。

手動確認する主要フロー:

- タスクの追加（空文字は拒否）・完了／解除・削除（「元に戻す」で復元）
- リロード後もデータが残る
- 日／週／月の切替、◀▶と「今日」での移動
- タイマーの開始・一時停止・リセット・時間切れ表示・「完了にする」
- ライト／ダークテーマ両方で表示が破綻しない
