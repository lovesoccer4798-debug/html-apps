# Changelog

このアプリのユーザーに見える変更を記録する（[Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) 形式・[Semantic Versioning](https://semver.org/lang/ja/) 準拠）。

## [1.68.0] - 2026-08-01

### Added

- **「今日の整理」**を追加。今日の「日」ビューの上に小さな「整理」ボタンが出ます（画面は縦に伸びません）
  - 今日の予定・タスク・ルーティンを一覧で見て、**やらないものをまとめて選んで、今日だけ外せます**
  - 外すのは**その日の分だけ**。ルーティンの設定もほかの日も変わりません。単発のものは削除されますが「元に戻す」でまとめて戻せます
  - **できたものにチェック**を入れてまとめて完了にもできます。その場から追加もできます
  - 朝（〜11時）は「朝の整理」、夜（17時〜）は「夜の整理」になり、文言とボタンの並びが入れ替わります
- **Googleカレンダーの「常時連携」**を追加（設定 → Googleカレンダー連携）。「新しい予定・タスクを、はじめからGoogleにも登録する」をオンにすると、追加画面のスイッチが最初からオンになります。**1件ずつオフにする今までのやり方はそのまま**です
- **単発のタスクもGoogleカレンダーに登録できる**ように（今までは予定だけでした）。Google側では「予定」として入ります
- **カレンダー上部の固定を3段階から選べる**ように（設定 → 画面）。**全部**（日付・タブ・フィルタ）／**上のバーだけ**（検索・テーマ・設定が並ぶ1行だけ残す）／**固定しない**
- ヘルプに「Googleに送られるのはどれ？」「日をまたぐ予定はGoogleでも1本になる？」「Googleに送られないものは？」「今日の整理」の項目を追加

### Fixed

- **日をまたぐ予定（旅行・帰省など）がGoogleカレンダーで1日ぶんに縮んでいた**のを修正。終了日まで1本の帯で入るようになりました
- 終了時刻が開始より前の予定（22:00〜01:00 など）が、Googleで正しく登録できなかったのを修正。翌日の終了として入ります
- タスクを削除・編集したとき、Google側に反映されていなかったのを修正

## [1.67.0] - 2026-07-31

### Added

- **天気**を表示できるように（設定 → カレンダー →「天気」）。**Open-Meteo**（APIキー不要・登録不要・無料）から取得します。**追加の課金は発生しません**
  - 「日」の画面の上に `☀️ 晴れ 32°/24° ☔️20%`、「時間」の日付見出しに小さく天気の絵文字が出ます
  - 地点は主要16都市から選ぶか、「現在地から設定する」で1回だけ位置情報を使えます。**位置情報はこの端末にだけ保存され、どこにも送りません**（天気の取得に緯度経度だけを使います）
  - 3時間おきに取り直し、取れないときは前回の内容を使います（オフラインでも壊れません）
  - 既定はオフです
- **祝日が本物のデータになりました**（holidays-jp・APIキー不要・無料）。これまでは計算で推定していたので、臨時の祝日や法改正には追従できませんでした
  - 「日」の画面に**祝日の名前**（例：海の日）が出ます。「時間」の1日表示にも出ます
  - 「平日」「土日祝」のルーティンの判定も、この本物のデータを使います
  - 取得は30日に1回だけ。取れないとき・データの範囲外の日は、これまでどおりの計算を使います
- **Notionに「天気」も送れるように**（設定 → Notion連携）。Notionの「天気」（晴れ／くもり／雨／雪のセレクト）に自動で入ります
  - 天気のデータが無い日は送らないので、**手で選んだ内容が空で上書きされることはありません**
  - 「天気」の設定がオフのあいだは送りません

## [1.66.0] - 2026-07-30

### Added

- **YouTubeのリンクが、サムネイル＋動画タイトル＋チャンネル名のカードで見える**ように。予定・タスクの詳細画面と、思い出カレンダーのカードで、押す前に何の動画か分かります
  - APIキーも登録も不要（YouTubeのoEmbed）で、**追加の課金は発生しません**
  - 一度読んだ動画の情報は端末に保存するので、2回目からは通信しません
  - サムネイルは動画のURLから組み立てるだけなので、**通信できないときでも出ます**。タイトルが取れないときは「YouTube を開く」に戻るだけで、リンクはいつでも開けます
  - YouTube以外のリンク（Zoomなど）は今までどおりのボタンです
  - `youtu.be` / `/shorts/` / `/embed/` / `m.youtube.com` / `music.youtube.com` にも対応

### Changed

- **「時間」ビューで、時間が重なった予定・タスクが横に分かれる**ように（Googleカレンダーと同じ見え方）。今までは枠が全部同じ幅で重なって、完了ずみの半透明とまざって読めなくなっていました
  - 重なっていない予定は今までどおり幅いっぱい。重なったところだけ分かれます
  - 右があいていればその分だけ広がります
  - 横に並べる数の上限は 1日=4 / 3日=3 / 週=2。それを超えたときは、左を少しずつずらして重ねるので、**何本あるか分かって、それぞれタップできます**
  - 枠が狭いときはタイトルを1行に切ります（文字が1文字ずつ縦に並ぶのを防ぐため）

## [1.65.0] - 2026-07-30

### Added

- **タイマー（フォーカス）画面から、そのままリンクを開ける**ように。リンク（YouTubeなど）を設定したタスクでタイマーを動かすと、画面の右上に小さく「リンク」ボタンが出ます。タイマーを止めたり戻ったりせずに、そのまま動画へ飛べます（時間は終了時刻で数えているので、動画を見ているあいだもタイマーは進みます）。リンクが無いタスクではボタンは出ません。タイマーのデザイン6種それぞれに色を合わせています
- **Notion連携に「その日にやったタスクの名前も送る」を追加**（設定 → Notion連携）。オンにすると、完了したタスクのタイトルだけを箇条書きでNotionの**「タスク」プロパティ**に入れます
  - 使う前に、Notionのデータベースに「タスク」という名前の**テキスト（リッチテキスト）プロパティ**を追加して、Workerを最新の `notion-worker.js` に貼り替えてください
  - オフのままなら今までと何も変わりません（送る内容も増えません）

## [1.64.0] - 2026-07-30

### Added

- **予定・タスクの色に2色追加**（合計11色）
  - **バナナ** … オレンジとも今までのイエロー（マスタード寄り）とも違う、はっきりした黄色
  - **パステルピンク** … 今までのピンクより薄い、やさしいピンク
  - この2色は明るいので、アプリ全体のアクセントカラー（白文字のボタンに使う色）には出していません。予定・タスク・カレンダー・ルーティン・色ルールの色として選べます

### Changed

- **プロフィール帳の「編集」を右上の小さなボタンに変更**。下の大きなボタンだと、読む画面なのに書くことを促してしまうため。書いていない項目があるときは、カードの下に「まだ書いていない項目が◯つあります」と小さく添えるだけにしました
- **誕生日に「年」まで入れると、年齢を自動で計算**するようにしました（例：`2001/12/18` → `24歳`）。年を重ねても勝手に切り替わります
  - `2001-12-18` `2001年12月18日` `2001.12.18` などの書き方にも対応
  - 年が分からないとき（`12/18` など）は、今までどおり年齢を手入力できます
  - 自動計算中の年齢欄は読み取り専用（点線枠）になります。**手入力した年齢は消さずに残す**ので、誕生日から年を消せばその値に戻ります
  - 入力欄の並びを「誕生日 → 年齢」にしました

## [1.62.0] - 2026-07-30

### Added

- **思い出シェアカレンダー**を追加（設定 →「連携・同期」→「思い出シェアカレンダー」）。仲間・家族・仕事仲間と、**終わったこと**を持ち寄るための共有カレンダーです
  - **ふだんの画面には出ません。** 「日・週・時間・月・年」には出さず、専用の「思い出」タブにだけ出ます（自分用がメインという前提を崩さないため）。カレンダーにも出したいときは設定のスイッチでONにできます。この選択は**この端末だけ**のもので、相手の画面には影響しません
  - 「思い出」タブは、思い出カレンダーを作る（または参加する）まで出てきません
  - **写真**を1件あたり4枚まで残せます。長辺1280pxに縮めて1枚240KB以内に圧縮するので、**Firebaseの無料枠のまま**使えます（追加の課金は発生しません）。1カレンダー100枚まで＝約24MB
  - **スタンプ**（❤️🔥😂🥹👏🎉🍻📸）を1人1個押せます。だれが押したかも出ます
  - **ひとことコメント**を1件につき30件まで残せます
  - **セット記録**は既存の「詳細」をそのまま使います（ライブの曲順・旅行で行った場所などを番号つきで）。リンク（YouTube等）も今までどおり貼れます
  - 新しい順のタイムラインで、年月ごとに区切って表示します
  - 設定に「写真 n/100枚・約xxMB」の使用量と、「使っていない写真を片づける」を用意しました
  - **Firebaseのルールに1行の追加が必要です**（設定の案内文と `specs/task-calendar-memories.md` に記載）。追加しないと写真の保存だけができません

### Fixed

- 共有カレンダーの「削除」ボタンが、赤い文字と赤い背景が重なって読めなくなっていたのを修正
- タブが7つになると「カレンダー」「ルーティン」の文字が2行に折り返していたのを修正

## [1.61.0] - 2026-07-30

## [1.60.0] - 2026-07-29

### Added

- **タイマー（フォーカス）画面のデザインを6種類から選べる**ように（設定 →「タイマーのデザイン」）。残り時間の見せ方だけが変わり、停止・一時停止・完了の操作や時間の数え方は今までどおりです。配色テーマとは別の設定なので、好きな組み合わせで使えます
  - **ネオンパルス** … 発光するネオン管のリング
  - **砂時計** … 上の砂が減り、下に積もっていく

  - **リキッドドロップ** … カプセルの水位が下がる（波・泡つき）
  - **ターンテーブル** … 回るレコード盤とトーンアーム（一時停止で回転も止まる）
  - **ブルーム** … 経過とともに葉が増え、完走で花が咲く

## [1.59.0] - 2026-07-29

- カレンダー本体の横スワイプで前後の日・週・月へ移動（日・週・時間・月・年すべてのビュー。カードの左スワイプ操作とは干渉しない）
- 時間割の時間枠は、枠そのものを掴んで上下にドラッグすると長さを保ったまま移動できる（つまみは開始・終了の個別調整）

- 時間枠の「予定を追加」「×」ボタンを左下へ移し、右下のつまみと重ならないようにした

## [1.2.0] - 2026-07-17

### Added

- メールアドレス＋パスワードの新規登録・ログイン画面（設定の「アカウントと同期」）: Googleが使えない環境でも同期できる。パスワード再設定メールにも対応
- 同期のON/OFF切替: ログインしたまま「この端末にのみ保存」へ切り替えられる

- 設定に「よく会う人」リスト（最大30人）: 登録しておくと予定の「誰と」でワンタップ選択。リストにない人はその場で自由入力
- 時間割ビューで空き時間をタップすると時間枠が出て、上下のつまみをドラッグして開始・終了を調整→「予定を追加」でそのまま作成（Googleカレンダー風・15分刻み）
- 予定の終了時刻が時間割ビューのブロックの長さに反映される

### Changed

- 検索からのジャンプ先が、いま見ているビュー（日・週・時間・月）を保つようになった（以前は必ず日ビュー）

## [1.1.0] - 2026-07-17

### Added

- 時間割ビュー（表示切替の「時間」タブ）: Googleカレンダー風の日にち（横）×時間（縦）グリッド。1日／3日／週を切替でき、既存の日・週ビューはそのまま
  - 時間つきの項目は開始時刻の位置にブロック表示（所要時間があればその長さ）。時間なしは「終日」の段へ
  - 空いている時間帯をタップ→その日時が入った追加シート、ブロックをタップ→編集。今日の列には現在時刻の赤い線
- 検索（カレンダー画面の虫めがね）: タスク・予定・メモ・日記をキーワード検索。候補の右に年月日と曜日が出て、タップでその日のデイリーへジャンプ（繰り返しは直近の予定日へ）

### Fixed

- 土曜=青・日曜/祝日=赤の色がどのビューにも反映されていなかった問題（色の変数定義が抜けていた）
- ホーム画面に追加したPWAでGoogleログインが失敗する問題: ポップアップが開けない環境ではリダイレクト方式で自動的にログインするよう変更。失敗時はエラーコードも表示

## [1.0.0] - 2026-07-16

### Added

- カレンダー共有（Firebase Phase B）: 設定の「共有カレンダー」から作成して8桁の招待コードを渡すと、相手もコード入力だけで参加できる（Googleログインが必要）
- 権限管理: オーナーはメンバーごとに「編集可（既定）／閲覧専用／解除（非表示）」を切替可能。閲覧専用はアプリ内の追加・チェック・削除がブロックされ、サーバー側ルールでも書き込み拒否
- 共有カレンダーはフィルタチップ・追加シートのカレンダー選択・色タグ・予定表モードに「（共有）」付きで並び、自分のカレンダーと同じ操作感で使える
- 変更はリアルタイムで相手の画面に反映（3秒デバウンス送信・差分がないときは書き込まない=無料枠にやさしい）。退出・オーナーによる削除にも対応

## [0.9.0] - 2026-07-16

### Added

- Googleログインとクラウド同期（Firebase Phase A）: 設定の「アカウントと同期」からログインすると、タスク・予定・ルーティン・目標・睡眠・メモ等が自分専用のクラウド領域へ自動バックアップされ、別端末でも復元できる（ビジョンボードの写真は端末内のみ）
