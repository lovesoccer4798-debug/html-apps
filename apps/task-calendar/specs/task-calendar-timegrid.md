# 「時間」ビューの重なり表示

- 対象アプリ: Task Calendar（TaskARE）
- 状態: 実装済み（v91）

## 1. 直したかったこと

「時間」ビューは、時刻つきの予定・タスクを縦軸（時間）に置くタイムライン。これまでは**すべての枠が列いっぱいの幅**で描かれていたため、時間が重なると枠どうしが完全に上書きし合っていた。完了ずみの項目は半透明（`opacity: .55`）なので、重なった部分が透けて混ざり、下の予定も上の予定も読めない状態になっていた。

目標は Googleカレンダーと同じ「**重なったら横に分かれる**」挙動。

## 2. レイアウトの決め方（`tgLayout`）

1. **かたまり（クラスタ）に分ける** — 開始時刻順に並べ、直前までの最大終了時刻より後に始まる項目が来たら、そこでかたまりを切る
2. **かたまりの中で列に割り当てる** — 各項目を「その時点で空いている一番左の列」に入れる（列ごとに最後の終了時刻を覚えておく）
3. **右へ広げる** — 自分の右側の列が、自分の時間帯のあいだ空いているなら、その分だけ横に広げる

結果、重ならない項目は列いっぱいのまま、重なった項目だけが等幅で分かれる。

### 細くなりすぎるときは階段状にする

列数が増えるほど1本が細くなるため、表示日数ごとに上限を決めている。

| 表示 | 横に並べる上限 |
|---|---|
| 1日 | 4列 |
| 3日 | 3列 |
| 週（7日） | 2列 |

上限を超えるかたまりは、**左を10pxずつずらして重ねる**（開始が早いものが下、遅いものが上）。どれも左端が見えるので、何本あるかが分かり、それぞれタップできる。

### 幅が狭いときの文字

枠の実測幅が 56px 未満になったら `is-narrow` を付け、タイトルを**1行に切って省略**する（付けないと、幅より1文字が大きいときに1文字ずつ縦に並んでしまう）。あわせて時刻の行は隠す。判定は描画後の `requestAnimationFrame` で `offsetWidth` を見て行う。

## 3. 長さの決め方（従来どおり）

- 予定: 開始〜終了時刻（最低15分）
- タスク: 所要時間（`minutes`）
- どちらも無ければ1時間

重なり判定にはこの「実際の時間」を使う。見た目の最低高さ（20px）は判定には使わない。

## 4. 見た目

枠には背景色と同じ色の1px縁（`box-shadow: 0 0 0 1px var(--tc-bg)`）を付けて、隣り合ったときの境目が分かるようにする。
