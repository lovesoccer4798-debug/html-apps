# 人ページ（プロフィール帳）

- 対象アプリ: Task Calendar（TaskARE）
- 状態: 実装済み（読むモードの追加は v88）

## 1. 目的

予定の「誰と」に入れた名前をタップすると開く、その人だけのページ。

- **一緒の予定**（その人と過ごした日の一覧）で、関係の履歴が見える
- **プロフィール帳**に、その人のことを自分の言葉で書き残しておける（**自分だけのメモ**。相手には共有されない）

プロフィール帳の価値は「書くこと」ではなく「**あとから読み返して、当時こう思っていたと気づくこと**」にある。したがって画面の既定は「読む」であり、「書く」は一段奥に置く。

## 2. データ

`db.peopleProfiles[名前]` に項目ごとの文字列で持つ。クラウド同期の対象（`SYNC_KEYS_OBJ`）だが、共有カレンダーには一切送らない。
一覧整理用のメタ情報は `db.peopleProfiles[名前]._meta` に入れる。既存のプロフィール本文とはキーを分けるため、過去データと衝突しない。

| キー | 項目 | 種類 |
|---|---|---|
| `nick` | 呼び方（ニックネーム） | 1行・60字 |
| `relation` | 関係性 | 1行・60字 |
| `birthday` | 誕生日 | 1行・60字 |
| `age` | 年齢 | 1行・60字 |
| `personality` | 性格 | 複数行・2000字 |
| `likes` | 好きなところ | 複数行・2000字 |
| `met` | 出会ったきっかけ | 複数行・2000字 |
| `next` | 次に会ったらしたいこと | 複数行・2000字 |
| `memory` | 思い出・エピソード | 複数行・2000字 |

| メタキー | 用途 |
|---|---|
| `_meta.favorite` | プロフィール帳一覧で上部にピン留めするお気に入り |
| `_meta.groups` | 自由に作ったグループフォルダ名の配列 |
| `_links.instagram` / `_links.x` / `_links.note` / `_links.tiktok` / `_links.website` | その人のSNS・外部ページへのリンク |
| `_guestbook[]` | 相手本人に書いてもらったプロフィール帳回答（自分メモとは別枠） |
| `_requests[]` | 発行済みの「本人に書いてもらう」リンク控え（回答取り込み用） |

グループ名の一覧は `db.settings.peopleGroups` に持つ。プロフィール側に残っているグループ名も一覧へ復元する。

### 年齢は誕生日から自動計算する

誕生日は自由入力だが、**「年」まで書かれていれば**（`2001/12/18` `2001-12-18` `2001年12月18日` `2001.12.18` など、数字が3つ以上あり、1つめが1900〜2200の範囲）その年の年齢を今日時点で計算する。年を重ねても自動で切り替わるようにするため。

- 年が分かる → 年齢は自動。編集画面の年齢欄は**読み取り専用**（点線枠）にして、その旨を注記する
- 年が分からない（`12/18` など） → 従来どおり年齢を手入力する
- 手入力した年齢は**消さずに保存したまま**にする。誕生日から年を消すと、その値に戻る
- 読むモードのチップは「24歳」と「12/18」（年は年齢チップに出るので、誕生日チップは月日だけ）

## 3. 2つのモード

`ui.personEdit` で切り替える。人ページを開いた時点で決める。

| 状態 | 開くモード |
|---|---|
| 1項目でも書いてある | **読むモード** |
| 何も書いていない | **書くモード**（空の読み物を見せても意味がないため） |

### 読むモード

- **ヘッダー**: 頭文字のアイコン（大）／ニックネーム（大きく）／ニックネームがあれば本名を小さく添える／関係性・年齢・誕生日をチップで並べる
- **SNS・リンク**: Instagram / X / note / TikTok / その他URLが保存されていれば、外部ページへ開けるチップとして出す
- **本文**: 性格・好きなところ・出会ったきっかけ・次に会ったらしたいこと・思い出エピソードを、アイコンつきのブロックで縦に並べる。**空の項目は出さない**
- **本人に書いてもらう**: ログイン中に「本人に書いてもらうリンク」を発行できる。相手はURLから未ログインで回答し、回答は `_guestbook[]` としてプロフィール内に取り込まれる
- **編集への入口はカード右上の小さなボタン**（ペンのアイコン＋「編集」）。読む画面なので、書くことを促しすぎない大きさにする
- 書いていない項目があるときは、カードの下に「まだ書いていない項目が◯つあります」と小さく添えるだけにする（ボタンにはしない）

### 書くモード

従来どおり全項目の入力欄を並べ、入力から400msで自動保存する。下の「書けた！プロフィール帳を見る」で読むモードへ戻る（1項目も書かれていなければ戻らずトーストで知らせる）。
SNS・リンク欄は自分メモの下に置く。`@username` やIDだけ入力された場合は、対応サービスのURLへ正規化する。

### 本人に書いてもらうプロフィール帳

v101で追加。懐かしい紙のプロフィール帳のように、相手本人に自分のことを書いてもらう。

- 持ち主: 人ページの読むモードからURLを発行（Firebaseログイン必須）
- 相手: `?profwrite=コード` のURLを開き、任意の項目だけ入力して送信（ログイン不要）
- 保存先: Firestore `profileRequests/{code}` に回答が入り、持ち主のアプリが開いたとき `_guestbook[]` へ取り込む
- 自分で書くプロフィール本文とは別枠に表示する
- 質問項目は懐かしさ・楽しさ優先:
  - 名前・呼ばれ方
  - みんなから何て呼ばれてた？
  - 最近ハマっていること
  - 好きなもの・推し
  - 自分をひとことで言うと？
  - 好きな人はいる？
  - 過去一の失敗
  - 最近うれしかったこと
  - いつかやってみたいこと
  - 最後にひとこと

## 4. 画面の並び

プロフィール帳を上、一緒の予定を下に置く（読むことが目的の画面なので）。

## 5. 入口

- 下部タブ →「プロフィール」
- 振り返り →「よく会った人」の行
- 予定・タスクの一覧に出る人タグ

### プロフィール帳一覧

下部タブの「プロフィール」は、プロフィール帳だけを確認・編集するための入口。

- `db.people`（設定で登録した人）・予定の「誰と」に出た人・`db.peopleProfiles` に保存済みの人をまとめて並べる
- 行には名前、プロフィール帳の記入項目数、一緒の予定数を出す
- 行をタップすると既存の人ページを開く。既に何か書いてある人は読むモード、空の人は書くモードから始める
- v99: 人数が増えたときのために、一覧に整理機能を追加する
  - お気に入り（星）: 上部に「お気に入り」セクションとしてピン留め
  - グループフォルダ: 自由な名前のグループを作り、人ごとに複数所属できる
  - 検索: 名前・呼び方・関係性・プロフィール本文・グループ名を対象に絞り込む
  - あかさたなジャンプ: 先頭がひらがな/カタカナの名前は行で絞り込める。漢字・英字など読みが自動判定できないものは「他」に入れる（将来よみがな欄を足す余地を残す）

## 6. 色の注意

チップの文字色は `--tc-accent` を使う。`--tc-accent-ink` は**アクセント色の背景に載せる**ための文字色で、カード背景の上で使うとダークモードで読めなくなる（v88で修正済み）。
