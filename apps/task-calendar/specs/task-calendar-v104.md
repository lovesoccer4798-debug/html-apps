# v104: 大切な日の通知・記録のハイライト・リンク・デザイン

2026-09-22 オーナー依頼。TaskAREの既存機能拡張として実装し、NESTのPhase構成は変更しない。

- 記念日に通知日（7/5/3/2/1/0日前、複数可）と、日付が動く祝日の選択を追加。敬老の日は毎年9月第3月曜として計算する。既存記念日は未設定＝通知なし。
- オーナーは「アプリを閉じていてもスマホに届く」を選択。Web Push対応Service Workerと、専用Cloudflare Worker+KV+Cronの配信側を用意する。既存のtask-calendar-apiとは分離。日本時間9時に対象日の通知を配信、9時台の定期実行で失敗再試行。アプリ内にも対象日の案内を表示。
- HTTPS/ホーム画面追加/通知許可、専用通知Workerの初期設定・配信テストが必要。設定前を通知有効と表示しない。無料枠内の個人利用想定であり無制限・配信保証とは言わない。
- あのね。ノートは既存の文字列データを維持。HTTP(S) URLと `[名前](https://...)` を安全なリンクに変換。編集にリンク挿入ボタンを追加。HTMLは解釈しない。
- 振り返りは外部API費用・日記の外部送信なし。端末内で明示的な語句と出現日数を集計し、原文と日付を添える。「嬉しい」「懐かしい」「振り返り」等を本人の気持ちの診断として断定しない。生成AIと偽らず「記録のハイライト」とする。
- デザイン3種: コラージュ手帳、活版ポスター、夜の展示室。配色以外に素材画像・罫線・見出し・セル・操作部を変える。明暗切替、スマホ/PC、オフライン資材に対応。
- 検証は架空データ。通知は日付境界/祝日移動/複数選択/再送、リンクは不正URL/HTML、ハイライトは根拠/重複/空記録、テーマは全画面サイズの明暗を確認する。
