# 原点ノート

2026-09-20 オーナー承認: 専用ページでゆっくり読み返す。既存TaskARE内の機能追加として扱う。

- メニュー「原点ノート」から開く。今日画面への自動表示はしない。
- 「大切にしたいこと」（ハート・緑）と「やめたい行動」（一時停止・紫）のタブで分類。色だけでなく見出し・アイコンで区別する。
- 各項目に言葉/行動（必須120字）、理由（任意4000字）、参考資料（最大5件: 書名/ページ名と任意HTTP(S)リンク）、今の自分からひとこと（任意2000字）を保存する。
- 読む画面は全文表示。上に固定、編集、削除が可能。削除は確認と既存の取り消しトーストを使う。
- 編集は明示保存。未保存の変更がある状態で閉じる場合は破棄確認する。
- `db.originNotes[]`: id, kind(value/stop), title, reason, sources[{title,url}], reflection, pinned, createdAt, updatedAt。
- localStorage・個人のFirebase同期・JSONバックアップに含める。共有カレンダーやNotionには送らない。既存データの削除やFirebaseルール変更は不要。
- 検証: 追加/編集/分類/固定/削除取り消し/再読込、URL検証、表示エスケープ、個人同期のペイロード、スマホ/PC明暗の読みやすさ。
