# Googleカレンダー連携のしくみ（何が同期され、何がされないか）

- 対象アプリ: Task Calendar（TaskARE）
- 状態: 実装済み（v93で複数日・日またぎ・タスク対応・常時連携の既定を追加）
- 関連: [Googleカレンダー連携（接続まわり）](task-calendar-gcal.md)

## 1. 全体像：向きが2つある

| 向き | いつ動く | 中身 |
|---|---|---|
| **Google → アプリ（読み取り）** | 連携していれば**常に自動** | Googleの予定をカレンダーに表示。**アプリ側からは編集も削除もできない**（読み取り専用） |
| **アプリ → Google（書き込み）** | その予定・タスクで**スイッチをONにしたときだけ** | アプリで作った予定・タスクをGoogleに登録。編集・削除もGoogle側に反映 |

この2つは別物。読み取りは全部入ってくるが、書き込みは**選んだものだけ**。

## 2. Google → アプリ（読み取り）

- **月単位でまとめて取得**する（表示している月が変わったときに、その月ぶんを1回だけ）
- くりかえしの予定は `singleEvents: true` で**1回ずつに展開**して受け取る（毎週の会議も、各回が個別に出る）
- 取ってくるのは `id / タイトル / 開始 / 終了 / 場所 / Meetリンク` だけ。**説明文・参加者・添付は取らない**
- 同じ日・同じ時刻・同じタイトルの予定がアプリ側にもある場合は、**二重表示しない**（アプリ側を優先）
- 表示は青色。設定の「Googleの予定をカレンダーに表示する」でまとめて隠せる
- **アプリからは変更できない**。詳細を開いても編集ボタンは出ない

## 3. アプリ → Google（書き込み）

### 対象になるもの・ならないもの

| 種類 | Googleへ | 備考 |
|---|---|---|
| 単発の**予定** | ✅ | |
| 単発の**タスク**（v93〜） | ✅ | Googleには「予定」として入る。Googleにタスクの概念で入るわけではない |
| **くりかえし**の予定・タスク（毎日・毎週・平日…） | ❌ | ルーティンは件数が多く、Google側と二重管理になるため対象外。ONにしても送られない |
| **ルーティンから生成された項目** | ❌ | 上と同じ（くりかえし扱い） |
| 共有カレンダー・思い出カレンダーの項目 | ✅（スイッチONなら） | 自分のGoogleカレンダーに入る |

### 時間の入り方

| アプリでの入れ方 | Googleでの見え方 |
|---|---|
| 時刻なし（終日） | **終日の予定**。1日ぶん |
| 時刻なし＋**終了日あり**（旅行・帰省など） | **終日の帯**。開始日〜終了日をまたいだ1件になる（v93で対応） |
| 開始時刻＋終了時刻 | **まったく同じ時刻**で入る |
| 開始時刻だけ | 開始〜**1時間後**まで（アプリ側の「所要時間」ではなく一律1時間） |
| 開始 > 終了（例 22:00〜01:00） | **翌日の01:00まで**として入る（v93で対応） |
| 時刻あり＋終了日あり | 開始日の開始時刻 〜 **終了日の終了時刻** |

タイムゾーンは端末の設定をそのまま送る。

### 一緒に送られるもの

- **タイトル** → Googleの「タイトル」
- **場所** → Googleの「場所」
- **メモ**・**誰と**・**招待メールの追記** → Googleの「説明」にまとめて入る
- **招待メール**（予定のみ）→ Googleの参加者。入れると**あなたのGoogleアカウントから招待メールが届く**
- **Google Meet**（予定のみ）→ 会議リンクを自動発行

送られ**ない**もの: 日記／詳細（サブ項目）／リンク／色／カレンダーの分類／タイマーの所要時間／完了状態。

### 更新と削除

- アプリで編集して保存 → **Google側も同じ内容に更新**（スイッチONのまま／`gcalId` を覚えている）
- アプリで削除 → **Google側からも削除**
- 「元に戻す」→ Googleに**作り直す**（IDは新しくなる）
- Google側で消した／変えた場合 → **アプリには戻ってこない**（一方通行）

## 4. 常時連携（v93）

設定 → Googleカレンダー連携 →「**新しい予定・タスクを、はじめからGoogleにも登録する**」。

- ONにすると、追加画面の「これをGoogleカレンダーにも登録する」が**最初からオン**になる
- **1件ずつオフにできる**（都度選ぶ今までのやり方はそのまま残る）
- くりかえしは対象外なので、ONでも送られない
- 既存の予定・タスクをさかのぼって送ることはしない

※ 設定カードに出る「**常時連携中（自動更新）**」は別の話で、**アクセストークンが切れても自動で更新される**状態を指す（Cloudflare WorkerにGoogleのクライアントシークレットを置いてあるとき）。

## 5. 制限まとめ

- くりかえしはGoogleに送らない
- Google → アプリは読み取り専用（一方通行）
- 説明文・添付・参加者の返答状況はアプリに取り込まない
- 「所要時間（分）」はGoogleの終了時刻には使わない（開始時刻だけのときは一律1時間）
- 完了・未完了はGoogleに出ない
