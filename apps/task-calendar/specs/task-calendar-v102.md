# TaskARE v102 — プロフィール整理・計測・最近の記録

2026-09-20のオーナー依頼に基づく既存機能の改善。ロードマップのPhase構成は変更しない。

- プロフィール一覧は所属済みグループだけ表示する。所属変更は各人の編集画面のチェックボックス、または選択中グループの「人を追加」から行う。既存の所属データを維持する。
- 所要時間なしの未完了タスクにも再生ボタンを表示する。10/20/30/40/50/60分、または0秒からのカウントアップを選んで開始する。
- 計測は時刻差で計算し、一時停止・再開・再読込に対応する。完了時の予定時刻記録は従来の開始〜完了の実時刻・5分丸めを継承する。カウントアップの表示時間は一時停止分を除く。
- Notionまとめ送信は今日を含む直近10日（今日から9日前まで）の未反映・変更済み日を対象にする。日記の送信経路を確認し、失敗日は同期済みにしない。1日の失敗で他の日を止めず、失敗日を設定画面で表示する。
- メモ未入力の予定もタイトル・時刻を既存の「メモ」へ送る。新しいNotionプロパティやWorker変更は不要。
- ナイトリフレクションは銀色の海・水平線、スカイグラスは空の透明感として差別化する。新規テーマはタイポグラフィ主体の「エディトリアル」、緑と朱色の「ハーバー」、白黒と黄の「アトリエ」。全て明暗・OS追従に対応する。
- 「大切なことを見返すページ」は今回は提案のみ。候補は「原点ノート」。固定の大切な言葉、今日の1枚、振り返りの3つを検討し、達成率や連続日数を付けない。

## 検証

架空データのみで、所属表示・追加・解除、検索、時間未設定タイマー選択、一時停止・復元・完了、Notionの10日境界・日記本文・失敗再送、各テーマのスマホ/PC明暗表示を確認する。本番Notionへの送信は行わない。
