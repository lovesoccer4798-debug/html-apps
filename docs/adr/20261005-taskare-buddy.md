# ADR: Buddyの端末データと無料対話サーバーを分離する

- 日付: 2026-10-05
- 状態: 採用（本人承認済み、公開契約確認は別）

## 決定

BuddyはTaskARE内の独立追加機能。画像と設定は既存同期DBから分離して端末だけに保存。会話はメモリだけに置き、日記や予定への参照APIを渡さない。アプリ同梱FAQと生成AIの回答を区別する。認証は既存自動案内Workerの所有者限定 `/owner/status` へBearerを転送して委譲し、応答本文は読まず破棄する。自動案内Workerの設定やデータは変更しない。認証サーバーが利用不可ならBuddyも停止する。

自由対話は独立Worker + SQLite Durable Objectで直列に利用回数を予約し、固定のWorkers AI Free対応モデルを呼ぶ。無料条件フラグはデフォルトfalse。課金アラートを上限の代わりにしない。サービス側の無料プラン停止とアプリ側日30回制限の両方を使う。有料プランへ変更された場合の請求までフラグで保証できないため、公開前の実契約確認と運用引き継ぎを必須にする。

## 理由・影響

FAQだけでは自由対話の希望を満たせず、スマートフォン内LLMは容量・発熱・互換性の負担が大きい。外部AIは入力が外部へ送られ誤回答もあるため、本人の明示同意・最小送信・プレーンテキスト出力・予定操作禁止を守る。記憶やキャラクター画像のクラウド同期は初回の対象外。

公式確認: https://developers.cloudflare.com/workers-ai/platform/pricing/ 。無料条件・利用データ方針は有効化前にも確認する。
