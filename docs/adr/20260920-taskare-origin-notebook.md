# ADR: 原点ノートを個人用の専用ページとして保存する

- 日付: 2026-09-20
- 状態: 採用
- 関連: [原点ノート仕様](../../apps/task-calendar/specs/task-calendar-origin.md)

## 背景

オーナーが専用ページ、参考リンク、理由、やめたい行動を含む実装を希望した。既存アプリ内の承認済み機能追加で、ワークスペースのPhase変更はしない。

## 決定

既存の予定/プロフィールに混在させず、独立した `originNotes` 配列に保存する。個人同期の既存方式（ドキュメント単位の後勝ち）とバックアップを継承し、外部共有には含めない。閲覧を既定とし、入力は明示保存のダイアログにする。参考資料は名前だけでも保存でき、URLはHTTP(S)に制限する。

## 影響

共有ルールの追加は不要。既存のクラウド同期と同様に同時編集は後勝ちとなる。古いアプリでの同期が追加フィールドを落とすリスクも既存方式と共通のため、利用端末は最新版に揃える。大量のノートや長文はFirebaseの既存ドキュメント容量制約を受ける。
