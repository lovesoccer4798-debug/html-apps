# TaskARE: 閉じたアプリへの通知と端末内ハイライト

## 状態
採用（2026-09-23、オーナーのv104追加依頼）。実機配信の有効化は別途初期設定・受信確認後。

## 背景
静的PWAの画面内タイマーでは、アプリを閉じている間の大切な日を通知できない。日記のハイライトは無料・外部送信なしで実現したい。

## 判断
- Web Push + 専用Cloudflare Worker/KV/Cron。既存task-calendar-apiのビルド障害から分離。無料枠の個人運用を想定し、枠超過時の配信は保証しない。暗号化を独自実装せず、Apple対応のWeb Cryptoライブラリv2を固定。
- 接続キーは個人1名用。共有サービスではない。端末内にのみ保存し、既存の個人同期/バックアップに含めない。予定は既存anniversariesに互換追加し、配信側への反映成功を明示する。
- 複数端末は同じ配信予定を使用。初回登録で既存予定を上書きしない。記念日編集時のみ自動送信し、指紋照合で古い自動書込を拒否。手動更新は確認付き。KVの同時更新・配信記録の厳密な排他は非保証として明記。
- 語句抽出は生成AIではなく、端末内の規則ベース。原文・日付・日数を添え、気分/心理状態を断定しない。テンプレートの繰り返しメモは各日の記録として水増ししない。
- ノートは文字列保存のまま。HTTP(S)と簡単な名前付きリンクをDOMテキストとa要素に描画。HTMLは解釈しない。
- 素材テーマはローカルの生成PNGと別CSSで追加。既存のテーマ値・ユーザーデータは変更せず、明暗の色対を定義。

## 影響
通知サーバーの初期設定、公開HTTPS版、端末の通知許可と受信テストが必要。画像をService Workerキャッシュへ追加するため初回取得量が増える。Push接続キーは各端末で再入力する。
